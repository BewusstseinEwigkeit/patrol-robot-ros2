# 00 · 从这里开始

> 面向：定位线负责人以及两位队友
> 对应计划：M1「全员共同月：Linux + ROS 2 实操」
> 工作区位置：Windows `D:\Vibe Coding\patrol-robot-ros2`；Ubuntu `/media/<你的用户名>/Data/Vibe Coding/patrol-robot-ros2`

---

## 这个工作区解决什么问题

计划表里 M1 的月末检查点是一句话：

> **不看教程能独立做出「launch 拉起 画圆 + 打印位姿 + 录包」三个节点。**

这句话有三个隐藏要求：

1. 你得真的懂 topic / service / launch / tf2 是什么，而不是背命令；
2. 你得有一条能重复跑通的路径，而不是"上次能跑这次忘了"；
3. 你得能证明它跑通了（否则月末例会上说不清楚）。

这个工作区把这三件事分别落成了：**四周递进的代码**、**一条命令的验收脚本**、**自动生成的验收报告**。

---

## 五分钟跑通（Ubuntu 22.04）

```bash
# 0. 切到 Ubuntu 后，先确认盘挂上了（双系统下 D 盘是 /media/<你的用户名>/Data）
ls "/media/<你的用户名>/Data/Vibe Coding/patrol-robot-ros2"

cd "/media/<你的用户名>/Data/Vibe Coding/patrol-robot-ros2"

# 1. 装 ROS 2 Humble（只需一次；已经装过会跳过）
bash scripts/setup_ubuntu_ros2.sh

# 2. 新开一个终端（让 ~/.bashrc 生效），或者：
source /opt/ros/humble/setup.bash

# 3. 自检
bash scripts/check_env.sh

# 4. 编译
bash scripts/build.sh
source install/setup.bash

# 5. 一键验收
bash scripts/acceptance.sh all
```

第 5 步全绿，M1 的检查点就算拿到了。

## 每一周做什么

| 周 | 你要掌握的东西 | 对应代码 | 验收 |
|---|---|---|---|
| W1 | 命令行、turtlesim、topic/node/service/param | `src/m1_turtle_basics`、`scripts/w1_console_circle.sh` | `acceptance.sh w1` |
| W2 | 建包、发布者、订阅者、colcon build | `src/m1_pubsub_demo` | `acceptance.sh w2` |
| W3 | launch、参数传递、rosbag 录放 | `src/m1_bringup` | `acceptance.sh w3` |
| W4 | tf2 坐标树、静态/动态变换 | `src/m1_tf2_demo` | `acceptance.sh w4` |

详细任务、要回答的问题和检查点见 `docs/02_逐周任务与验收.md`。

## 建议的学习顺序（重要）

**不要一上来就 `cat` 代码。** 正确顺序是：

1. 先读 `docs/02_逐周任务与验收.md` 里当周那一节，知道这周要"能独立做出什么"；
2. 自己先按 turtlesim 官方教程敲一遍（`ros2 run turtlesim turtlesim_node` 那一套）；
3. 卡住了再回来看本工作区的代码，**重点看注释里"为什么这么写"**；
4. 跑 `acceptance.sh wN`，全绿才算过；
5. 把踩到的坑写进 `docs/03_踩坑日志.md`（月末结题报告和简历素材全从这里出）。

第 5 步不是形式主义。计划表里的"踩坑日志从第一天写"是三个人里最容易偷懒、但回报最高的一件事。

## 遇到问题先看这里

| 症状 | 先查 |
|---|---|
| `ros2: command not found` | 没 source；`source /opt/ros/humble/setup.bash` |
| `Package 'xxx' not found` | 编译后没 source `install/setup.bash` |
| `bash: $'\r': command not found` | 脚本被存成了 Windows 换行，见踩坑日志第 1 条 |
| turtlesim 窗口没出现 | 在 SSH/无显示环境里跑；需要图形桌面 |
| 验收脚本卡住不动 | 上一次的 turtlesim 没退干净；`pkill -f turtlesim` |

更多见 `docs/03_踩坑日志.md`。
